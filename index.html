    곡 추가

    여러 곡을 한꺼번에 · 유튜브 링크로 추가

    입력 규칙 · 한 줄에 한 곡, “노래제목 - 가수” 순서로 적어요. 하이픈(-) 앞뒤는 한 칸씩 띄우고, 작품은 끝에 [작품] 으로 붙여요. 제목만 적어도 되고, 유튜브 영상·재생목록 링크도 그대로 붙여넣을 수 있어요.

    API 키가 없으면 가수·제목으로 영상을 찾을 수 없어요. 유튜브 링크는 키 없이도 바로 재생돼요.

    설정

    로그인하면 목록과 API 키가 내 구글 계정에 저장돼서, 어떤 폰·브라우저에서 로그인해도 똑같이 나와요.

    로그인하지 않으면 이 폰의 브라우저에만 저장돼요.

    비워 두면 “가수 제목”만 검색해요. 엉뚱한 영상이 자주 나오면 여기에 말을 붙여 보세요.

    폰 화면이 꺼지면 유튜브 재생이 멈추는 기기가 많아요. 켜 두면 배터리를 더 써요.

    API 키 받는 법
    1. console.cloud.google.com 에 구글 계정으로 들어가 새 프로젝트를 만듭니다.
    2. ‘API 및 서비스’ → ‘라이브러리’에서 “YouTube Data API v3”를 찾아 ‘사용’을 누릅니다.
    3. ‘API 및 서비스’ → ‘사용자 인증 정보’ → ‘사용자 인증 정보 만들기’ → ‘API 키’를 고릅니다.
    4. 만들어진 키를 복사해서 위 칸에 붙여넣습니다.
    5. 다른 사람이 쓰지 못하게, 키 설정의 ‘웹사이트 제한’에 이 앱 주소를 넣어 두면 안전해요.
    검색 한도
    • 검색 1번에 100점이 들고, 하루 한도는 10,000점이라 하루 약 100번 검색할 수 있어요.
    • 한 번 찾은 영상은 저장돼서 다시 검색하지 않아요.
    • 한도는 한국 시간 오후 4~5시경에 새로 채워져요.
    홈 화면에 바로가기 만들기
    • 크롬: 오른쪽 위 메뉴 → ‘홈 화면에 추가’
    • 사파리: 공유 버튼 → ‘홈 화면에 추가’
